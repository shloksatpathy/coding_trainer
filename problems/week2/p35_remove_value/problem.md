# P35 · Remove all occurrences

Read `n x`, then `n` integers. Build a linked list and remove every node whose value is `x` (free the nodes in C/C++). Print the list, or `Empty`.

**Focus:** removing the head is the special case — a dummy node or a pointer-to-pointer (`Node **`) in C removes it.

**Sample input** (also in `in.txt`):
```
7 6
1 2 6 3 4 5 6
```
