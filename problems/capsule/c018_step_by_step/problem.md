# C018 · Step by step

Read a whole number `x`. Change `x` step by step and print it after each step, one line each:

```
start: X
+5: X
*2: X
-3: X
```

Each line shows the new value of the same variable.

**Example**

Input (also in `in.txt`):
```
0
```
Output:
```
start: 0
+5: 5
*2: 10
-3: 7
```

**Focus:** updating a variable from its own value.
