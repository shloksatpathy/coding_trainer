# C009 · Columns

This program reads no input. Print this table:

```
Item        Qty
apple         3
banana       12
cherry      150
```

The first column is **10 characters wide, aligned left**; the second is **5 characters wide, aligned right**. Use your language's width formatting instead of typing the spaces.

**Focus:** padding a value to a fixed width, so that columns line up whatever the length of each value.
