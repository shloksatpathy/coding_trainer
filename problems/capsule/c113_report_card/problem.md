# C113 · Report card

The input is one line: a name and three whole-number scores. Store them in a record with a name and an array of three scores. Print `NAME: total T, average A, best B` with the average to 2 decimals.

**Example**

Input (also in `in.txt`):
```
Ada 90 85 77
```
Output:
```
Ada: total 252, average 84.00, best 90
```

**Focus:** a record can hold text and an array as fields.
