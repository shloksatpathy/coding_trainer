# C100 · Checkpoint: tic-tac-toe

The input is a tic-tac-toe board: 3 lines of 3 characters, each `X`, `O` or `.` (empty). At most one player has three in a row. Print `X wins` or `O wins` if that player has three in a row (a row, a column or a diagonal), otherwise `draw` if the board is full, otherwise `in progress`.

**Example**

Input (also in `in.txt`):
```
XXX
OO.
...
```
Output:
```
X wins
```

**Focus:** checkpoint for module 10: reading a character grid, checking rows, columns and diagonals with loops, and combining the results.
