# C084 · Swap case

Read one line of text. Print it with every lowercase letter made uppercase and every uppercase letter made lowercase; other characters stay as they are. The text has only plain English letters, digits, spaces and punctuation.

**Example**

Input (also in `in.txt`):
```
Hello World
```
Output:
```
hELLO wORLD
```

**Focus:** looking at each character, deciding what kind it is, and building the output one character at a time.
