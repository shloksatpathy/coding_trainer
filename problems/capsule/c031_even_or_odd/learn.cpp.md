**Learn · if and else**

`if (condition) { ... } else { ... }`: the first block runs when the condition is true, the second otherwise. Compare with `==` (a single `=` assigns), `!=`, `<`, `<=`, `>`, `>=`.

```cpp
if (t > 0) {
    std::cout << "above zero\n";
} else {
    std::cout << "zero or below\n";
}
```
