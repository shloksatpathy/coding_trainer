**Learn · if and else**

`if` runs its block only when the condition is true; `else` runs otherwise. A block is the indented lines after the `:`. Compare with `==` (a single `=` assigns), `!=`, `<`, `<=`, `>`, `>=`.

```python
t = int(input())
if t > 0:
    print("above zero")
else:
    print("zero or below")
```
