# C125 · Sort words

The first line has `n` (1 ≤ n ≤ 1000); the next line has `n` words of lowercase letters. Print them sorted by length from short to long, and alphabetically among words of the same length, one per line.

**Example**

Input (also in `in.txt`):
```
5
pear fig apple kiwi date
```
Output:
```
fig
date
kiwi
pear
apple
```

**Focus:** a custom order with two keys, on text instead of numbers.
