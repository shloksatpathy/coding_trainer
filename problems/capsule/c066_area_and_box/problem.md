# C066 · Compute or print

Write `area(w, h)`, which returns the area and prints nothing, and `draw_box(w, h)`, which prints a `w` × `h` box of `*` and returns nothing. Read `w h`, print `area: A`, then call `draw_box`.

**Example**

Input (also in `in.txt`):
```
3 2
```
Output:
```
area: 6
***
***
```

**Focus:** a function either computes a value and returns it, or does something such as printing. Keeping the two apart makes both reusable.
