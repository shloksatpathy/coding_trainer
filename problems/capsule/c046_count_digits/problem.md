# C046 · Count the digits

Read a whole number `n` ≥ 0. Print how many digits it has. Use a loop that removes one digit at a time.

**Example**

Input (also in `in.txt`):
```
12345
```
Output:
```
5
```

**Focus:** a `while` loop whose number of rounds is not known in advance, and the special case where it would not run at all.
