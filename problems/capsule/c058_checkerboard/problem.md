# C058 · Checkerboard

Read `n` ≥ 1. Print an `n` × `n` board: the square in row `r`, column `c` (counting from 0) is `#` when `r + c` is even and `.` when it is odd.

**Example**

Input (also in `in.txt`):
```
4
```
Output:
```
#.#.
.#.#
#.#.
.#.#
```

**Focus:** deciding each character from its row and column.
