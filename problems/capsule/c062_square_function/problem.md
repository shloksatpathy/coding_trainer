# C062 · Returning a value

Write a function `square(x)` that **returns** `x * x` (it prints nothing). Read two whole numbers `a b` and print `square(a) + square(b)`.

**Example**

Input (also in `in.txt`):
```
3 4
```
Output:
```
25
```

**Focus:** a function that returns a value can be used inside an expression, like a number.
