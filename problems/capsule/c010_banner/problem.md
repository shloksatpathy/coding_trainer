# C010 · Checkpoint: a banner

This program reads no input. Print this banner exactly, including the empty line before the last line:

```
+--------------------+
|  "Hello, World!"   |
|  Level 1 \ Day 1   |
+--------------------+
|  10 * 10 = 100     |
+--------------------+

Module 1 done!
```

Let the program compute `100` from `10 * 10`.

**Focus:** checkpoint for module 1: several lines, quotes and a backslash inside text, an empty line, and a calculated value.
