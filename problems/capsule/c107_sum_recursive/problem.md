# C107 · Sum of a list, recursively

The first line has `n` (1 ≤ n ≤ 1000), the second `n` whole numbers. Write a recursive `total(a, i)`, the sum of the elements from index `i` to the end (0 past the end), and print `total(a, 0)`.

**Example**

Input (also in `in.txt`):
```
4
1 2 3 4
```
Output:
```
10
```

**Focus:** recursion over an array: the index is the part of the problem that shrinks.
