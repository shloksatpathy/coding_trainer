# C069 · Power

Write `power(base, exp)` that multiplies in a loop (exp ≥ 0; anything to the power 0 is 1). Read `base exp` and print `base` to the power `exp`. The result always fits in 64 bits.

**Example**

Input (also in `in.txt`):
```
2 10
```
Output:
```
1024
```

**Focus:** a function with a loop and an accumulator, and choosing a type big enough for the result.
