**Learn · your first program**

A C++ program starts in `main`. `#include <iostream>` gives you `std::cout`; `<<` sends text to it, and `\n` ends the line. Every statement ends with `;`.

```cpp
#include <iostream>

int main() {
    std::cout << "Good morning\n";
    return 0;
}
```

prints `Good morning`.
