**Learn · your first program**

A C program starts in `main`. `#include <stdio.h>` gives you `printf`, which writes text; `\n` ends the line. Every statement ends with `;`, and `return 0;` reports that the program finished without errors.

```c
#include <stdio.h>

int main(void) {
    printf("Good morning\n");
    return 0;
}
```

prints `Good morning`.
