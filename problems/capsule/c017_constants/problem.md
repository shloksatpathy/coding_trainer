# C017 · Constants

Read a number of minutes `m`. Print `S seconds` and `MS milliseconds` on two lines. Name the two factors as constants, `SECONDS_PER_MINUTE` (60) and `MS_PER_SECOND` (1000), and use them.

**Example**

Input (also in `in.txt`):
```
1
```
Output:
```
60 seconds
60000 milliseconds
```

**Focus:** a constant gives a fixed number a name, so the code says what it means and the number is written only once.
