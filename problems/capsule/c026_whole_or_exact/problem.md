# C026 · Whole or exact

Read two whole numbers `total` and `count` (total ≥ 0, count > 0). Print `whole: Q`, the whole-number average, and `exact: X`, the exact average with 3 decimals.

**Example**

Input (also in `in.txt`):
```
7 2
```
Output:
```
whole: 3
exact: 3.500
```

**Focus:** the same two whole numbers give a different result with whole-number division and with decimal division.
