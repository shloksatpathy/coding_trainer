# C087 · Join with dashes

Read one line of words separated by spaces (maybe several, maybe at the ends). Print the words joined by `-`, with no other spaces.

**Example**

Input (also in `in.txt`):
```
the quick brown fox
```
Output:
```
the-quick-brown-fox
```

**Focus:** putting a separator between items, but not before the first or after the last.
