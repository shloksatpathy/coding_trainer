# C082 · First, middle, last

Read a word. Print `first: F`, `middle: M` and `last: L`: its first character, the character at index `length / 2` (counting from 0), and its last character.

**Example**

Input (also in `in.txt`):
```
hello
```
Output:
```
first: h
middle: l
last: o
```

**Focus:** text is a sequence of characters, each at an index counting from 0; the last one is at `length - 1`.
