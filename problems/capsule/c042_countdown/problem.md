# C042 · Countdown

Read a whole number `n` ≥ 0. Print `n`, `n - 1`, …, `1`, one per line, then `Liftoff!`. Use a `while` loop.

**Example**

Input (also in `in.txt`):
```
3
```
Output:
```
3
2
1
Liftoff!
```

**Focus:** a `while` loop repeats as long as its condition holds; the block must change something so that it ends.
