# C101 · Factorial, recursively

Write a recursive function `factorial(n)`: `factorial(0)` is 1 and `factorial(n)` is `n * factorial(n - 1)`. Read `n` (0 ≤ n ≤ 20) and print `factorial(n)`.

**Example**

Input (also in `in.txt`):
```
5
```
Output:
```
120
```

**Focus:** recursion: a function that calls itself on a smaller problem, with a base case that stops the chain.
