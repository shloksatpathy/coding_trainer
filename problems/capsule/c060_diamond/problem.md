# C060 · Checkpoint: diamond

Read `n` ≥ 1. Print a diamond of `2n - 1` lines: the pyramid from C054 with `n` lines, followed by the same pyramid upside down without its widest line.

**Example**

Input (also in `in.txt`):
```
3
```
Output:
```
  *
 ***
*****
 ***
  *
```

**Focus:** checkpoint for module 6: splitting a shape into parts and writing each part as nested loops.
