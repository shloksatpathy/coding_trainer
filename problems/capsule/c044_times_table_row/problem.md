# C044 · A row of the times table

Read a whole number `n`. Print `n * 1`, `n * 2`, …, `n * 10` on one line, separated by single spaces.

**Example**

Input (also in `in.txt`):
```
7
```
Output:
```
7 14 21 28 35 42 49 56 63 70
```

**Focus:** printing in a loop on one line: put a space between values, not after the last one.
