# C045 · Count even and odd

The first line has a whole number `n` ≥ 0; the second line has `n` whole numbers. Print `even: E` and `odd: O`: how many of them are even and how many odd.

**Example**

Input (also in `in.txt`):
```
5
1 2 3 4 5
```
Output:
```
even: 2
odd: 3
```

**Focus:** reading a list of values one at a time inside a loop, and counting with a variable per category.
