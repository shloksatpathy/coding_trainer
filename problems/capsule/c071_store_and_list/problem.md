# C071 · Store and list

The first line has `n` (1 ≤ n ≤ 1000); the second line has `n` whole numbers. Store them, then print them one per line as `position: value`, with positions counting from 1.

**Example**

Input (also in `in.txt`):
```
3
5 -1 8
```
Output:
```
1: 5
2: -1
3: 8
```

**Focus:** an array (a list in Python) keeps many values under one name; each has a position, its index, counting from 0.
