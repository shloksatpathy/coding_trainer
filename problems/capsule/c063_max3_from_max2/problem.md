# C063 · Functions calling functions

Write `max2(a, b)`, which returns the larger of two numbers, and `max3(a, b, c)`, which returns the largest of three by calling `max2`. Read three whole numbers and print `max3` of them.

**Example**

Input (also in `in.txt`):
```
1 2 3
```
Output:
```
3
```

**Focus:** building a bigger function out of a smaller one.
