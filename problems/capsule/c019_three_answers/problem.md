# C019 · Three answers

The input has three lines: a first name and a city (one word each), then a year. Print two lines:

```
NAME from CITY, since YEAR
That is N years before 2026.
```

where N is 2026 minus the year.

**Example**

Input (also in `in.txt`):
```
Ada
London
1843
```
Output:
```
Ada from London, since 1843
That is 183 years before 2026.
```

**Focus:** reading values of different types, in the order they come.
