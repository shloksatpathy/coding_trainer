# C036 · Weekday or weekend

Read a day number `d`: 1 is Monday and 7 is Sunday. Print `weekday` for 1 to 5, `weekend` for 6 or 7 and `invalid` for any other number.

**Example**

Input (also in `in.txt`):
```
1
```
Output:
```
weekday
```

**Focus:** `or` for a list of values, and handling input that is out of range.
