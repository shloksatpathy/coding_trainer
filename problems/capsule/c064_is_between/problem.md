# C064 · Yes or no

Write `is_between(x, lo, hi)` that returns true when `lo ≤ x ≤ hi` and false otherwise. The first line has `lo hi`, the second `n`, the third `n` whole numbers. For each number print `yes` or `no` on its own line.

**Example**

Input (also in `in.txt`):
```
1 10
4
0 1 10 11
```
Output:
```
no
yes
yes
no
```

**Focus:** a function can answer a question: it returns true or false, and the caller uses it in an `if`.
