# C065 · Distance on a line

Write `absolute(x)` (without a built-in function) and `distance(a, b)`, which returns `absolute(a - b)`. The first line has `n`; each of the next `n` lines has two whole numbers. Print the distance for each pair, one per line.

**Example**

Input (also in `in.txt`):
```
3
1 5
5 1
-3 4
```
Output:
```
4
4
7
```

**Focus:** small functions with one job each, combined.
