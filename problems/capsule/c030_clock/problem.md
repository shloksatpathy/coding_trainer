# C030 · Checkpoint: seconds to a clock

Read a number of seconds `s` (0 ≤ s ≤ 1 000 000). Print it as `H:MM:SS`: hours, then minutes and seconds with two digits each. Hours can go past 23.

**Example**

Input (also in `in.txt`):
```
3661
```
Output:
```
1:01:01
```

**Focus:** checkpoint for module 3: whole-number division and remainder, constants and formatted output.
