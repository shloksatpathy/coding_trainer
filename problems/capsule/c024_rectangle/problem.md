# C024 · Rectangle

Read the width and the height of a rectangle; both can be decimal numbers. Print `area: A` and `perimeter: P`, both with 2 decimals.

**Example**

Input (also in `in.txt`):
```
3 4
```
Output:
```
area: 12.00
perimeter: 14.00
```

**Focus:** reading decimal numbers from the input.
