# C025 · Round down, round up, cut off

Read a decimal number `x`. Print three whole numbers on one line: `x` rounded down, `x` rounded up, and `x` with its fraction cut off.

**Example**

Input (also in `in.txt`):
```
2.7
```
Output:
```
2 3 2
```

**Focus:** turning a decimal number into a whole number: three different rules, which differ for negative numbers.
