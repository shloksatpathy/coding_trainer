# C061 · Your first function

Write a function `greet(name)` that prints `Hello, NAME!`. The input has three names, one per line: call `greet` once for each.

**Example**

Input (also in `in.txt`):
```
Ada
Bob
Cy
```
Output:
```
Hello, Ada!
Hello, Bob!
Hello, Cy!
```

**Focus:** a function is a named block of code: write it once, run it as often as you call it.
