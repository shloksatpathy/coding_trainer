# C088 · Palindrome

Read a word of lowercase letters. Print `yes` if it reads the same backwards (a palindrome) and `no` otherwise. Compare the characters from both ends toward the middle.

**Example**

Input (also in `in.txt`):
```
racecar
```
Output:
```
yes
```

**Focus:** two indexes, one from each end, stopping at the first mismatch.
