# C068 · Digit sums

Write `digit_sum(n)` for n ≥ 0, using a loop. The first line has `n`, the second `n` whole numbers ≥ 0. Print their digit sums on one line separated by spaces, then `best: X` on a second line: the number with the largest digit sum (the first one if several tie).

**Example**

Input (also in `in.txt`):
```
4
19 55 100 9
```
Output:
```
10 10 1 9
best: 19
```

**Focus:** a function with a loop inside, called from another loop.
