# P04 · FizzBuzz

Read `n`. For each i from 1 to n print one line: `Fizz` for multiples of 3, `Buzz` for multiples of 5, `FizzBuzz` for both, otherwise the number.

**Focus:** check order matters (test 15 before 3 and 5). In Rust, write it once with `if/else` and once with `match (i % 3, i % 5)`.

**Sample input** (also in `in.txt`):
```
15
```
